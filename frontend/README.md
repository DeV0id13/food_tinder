# FoodTinder — интерактивный прототип

Три экрана: выбор рецептов → рацион → список покупок. Интерфейс на русском, оптимизирован для десктопа и адаптирован под узкие экраны.

- 12 тестовых рецептов: свайпы мышью/касанием, стрелки клавиатуры, кнопки выбора и отмена последнего свайпа.
- Фильтры по приёму пищи и времени, подробный рецепт с ингредиентами и приготовлением.
- Периоды 1, 3 и 7 дней, дата начала, назначение и замена блюд, 1–12 порций на каждый слот.
- Автозаполнение свободных слотов подходящими любимыми рецептами. Существующие блюда сохраняются.
- Список покупок по активному периоду, суммирование нормализованных ингредиентов, отметки покупок, копирование и скачивание TXT.
- При изменении количества продукта или исключении из списка его отметка покупки снимается.
- Данные сохраняются в localStorage этого браузера. Серверной синхронизации, пользовательской регистрации и Django API нет: это самостоятельный демонстрационный frontend.
- При сокращении периода скрытые дни остаются в плане, но не входят в расчёты покупок.
- Приватный доступ регулируется платформой Sites. Доступ не расширять без подтверждения владельца.

## Локальный запуск

`npm start` — HTTP-сервер на порту 4173 (требуется Python 3).

`npm test` — проверки расчётов и целостности тестовых данных на встроенном Node test runner.

Исходные статические файлы находятся в `public/`. Команда `npm run build` копирует их в `dist/` для размещения. Внешние JS-зависимости не требуются. Фотографии и шрифты хранятся локально, запросов к сторонним сервисам при работе приложения нет.

## Браузерная проверка

После установки Playwright и Chromium: `node tests/e2e.mjs`. Тест запускает локальный HTTP-сервер сам и проходит ключевой сценарий на четырёх ширинах экрана. Для нестандартной среды поддерживаются переменные `FOODTINDER_PLAYWRIGHT`, `FOODTINDER_CHROMIUM`, `FOODTINDER_BROWSER_ARGS` и `FOODTINDER_SCREENSHOTS`.

Проверено: 7 проверок расчётов; сквозной браузерный сценарий (свайп, отмена, фильтры, диалоги, назначения, порции, покупки, перезагрузка, экспорт, все периоды, дата, удаление, пустые состояния, демонстрационный пример); ширины 1440, 1024, 768 и 390 пикселей. Ошибок JavaScript и неудачных запросов не обнаружено.
