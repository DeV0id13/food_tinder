# Semgrep правила FT-07

Здесь хранятся **закреплённые** правила Semgrep CE. Набор `auto` не используется —
он меняется без ревью.

Источник: зафиксированная ревизия правил Semgrep Registry, скопированных в этот каталог.
При обновлении — указывать commit/дату источника в заголовке каждого файла.

Файлы:
- `python-dangerous.yaml` — опасное выполнение команд/кода, небезопасный SQL.
- `django-web.yaml` — применимые небезопасные веб-конструкции Django/DRF.

Каждое правило должно иметь `id`, `message`, `severity`, `languages`, `metadata`.
