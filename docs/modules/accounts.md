# FT-01 — accounts

Маршруты уже подключены через `config/urls.py` по префиксу `/api/v1/auth/`.
Дополнительных подключений интегратору не требуется.

| Метод | Путь | Поведение |
| --- | --- | --- |
| GET | `session/` | Текущий `{authenticated, id, email}`; устанавливает CSRF cookie. |
| POST | `register/` | Проверяет email и пароль, атомарно создаёт User и UserProfile, возвращает 201 `{id, email}` без входа. |
| POST | `login/` | Проверяет email/пароль через Django, создаёт сессию, возвращает 200 `{authenticated, id, email}`. |
| POST | `logout/` | Завершает сессию, возвращает 204 также для гостя. |
| GET | `profile/` | Возвращает только базовые поля своего профиля. |
| PATCH | `profile/` | Частично меняет только базовые поля своего профиля и возвращает полный профиль. |

Используются Django session cookie и DRF `SessionAuthentication`. Для каждого
`register/login/logout` явно вызывается стандартная проверка CSRF из
`SessionAuthentication`, включая анонимные запросы. Клиент получает `csrftoken`
через `GET session/` и передаёт актуальный токен в `X-CSRFToken`. После login Django
ротирует CSRF token, поэтому клиент перечитывает cookie. Приватные ответы и
ответ сессии помечены `never_cache`.

Email нормализуется существующим `UserManager`; повтор без учёта регистра
возвращает 400 по `email`, включая конфликт ограничения БД. Перед созданием
пользователя применяется Django `validate_password`; пароль хранится штатным
хешированием Django. Неверные учётные данные при входе возвращают одинаковую
ошибку `non_field_errors`.

Профиль содержит только `date_of_birth`, `gender`, `height_cm`, `weight_kg`.
Дата рождения не может быть в будущем, пол ограничен существующими choices и
пустой строкой, рост и вес должны быть положительными и помещаться в поля модели.
Неизвестные и запрещённые поля записи дают 400. Decimal выдаётся строкой.
Если у старого пользователя нет UserProfile, GET возвращает пустые значения без
создания записи; PATCH создаёт запись и применяет изменения.

Существующие модели подходят без изменений; миграции не нужны.
