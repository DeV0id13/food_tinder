# 0007. Закреплённые зависимости

**Контекст.** Разработчикам, CI и образам нужны одинаковые версии зависимостей.
Наборы для разработки, работы приложения и SAST различаются.

**Решение.** Python-зависимости управляются uv 0.13.9 и `uv.lock`. Базовые
зависимости используются группами `dev` и `prod`, `security` устанавливается
отдельно. Frontend использует pnpm с `pnpm-lock.yaml`. CI и Docker ставят
зависимости из lock-файлов в строгом режиме.

**Альтернативы.** Ручные списки прямых зависимостей оставляют транзитивные версии
плавающими. Один общий набор переносил бы тестовые и security-пакеты в runtime.

**Последствия.** Новые зависимости требуют обновления и проверки lock-файла.
Production не устанавливает pytest, линтеры, Semgrep или pnpm.
