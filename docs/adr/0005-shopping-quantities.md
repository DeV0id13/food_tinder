# 0005. Точные количества покупок

**Контекст.** Количество ингредиента масштабируется по порциям, например
`quantity × servings / base_servings`. Частное может быть периодическим.

**Решение.** Каталог хранит `Decimal`. Расчёт переводит каждое значение в
`Fraction` и точно суммирует по идентификатору ингредиента. Граммы, миллилитры
и штуки округляются вверх до целого после суммирования. JSON списка покупок,
CSV и TXT выводят целые значения. Версия количества хеширует точную сумму и
единицу, поэтому изменение ниже границы округления учитывается для отметок.

**Альтернативы.** `float` или деление с конечной точностью Decimal могут менять
результат на границе целого. Округление до суммирования завышает требуемую покупку.

**Последствия.** Расчёт воспроизводим и не зависит от контекста округления.
Пользователь видит целое количество, а каталог сохраняет точность исходных данных.
